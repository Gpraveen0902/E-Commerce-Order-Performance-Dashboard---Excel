# E-commerce Orders Performance Dashboard (Excel + Power Query)

## 1. Overview (Problem Statement)
A retail company lacked a reporting system to monitor order and sales performance across Brazil.  
This project addresses that gap by building an **interactive Excel dashboard using Power Query**, enabling tracking of order trends, delivery performance, product categories, customer locations, and payment types.

---

## 2. Objectives
- Track total, delivered, canceled, and processing orders  
- Measure average delivery time and on-time delivery percentage  
- Identify top and least performing states, cities, and product categories  
- Enable filtering by order status, location, product category, and payment type  

---

## 3. Tools Used
- **Microsoft Excel**  
- **Power Query**  
- **PivotTables and PivotCharts**  
- **Slicers (for interactivity)**  

---

## 4. Key Metrics (KPIs)
- Total Orders  
- Delivered, Canceled, Processing Orders  
- Average Delivery Time  
- On-Time Delivery %  
- Total & Average Sales  
- Top / Least Selling Categories  
- Quick / Late Delivery Cities  

---

## 5. Approach
- Cleaned and structured raw data using **Power Query**  
- Created relationships between tables (Orders, Payments, Customers, Order Items, Products)  
- Added calculated columns for delivery period and status  
- Built KPIs & charts using **PivotTables**  
- Applied **slicers** for easy filtering (without using DAX or Power BI)  

---

## 6. Dashboard Highlights
- Interactive slicers by order status, customer location, product category, and payment type  
- Trend line showing order growth over time  
- **Choropleth map** for top-selling states  
- Bar charts for quick vs. late delivery cities  
- KPIs showing order & delivery performance metrics  

---

## 7. Insights
- **92%** of orders were delivered on time  
- **Average delivery time:** 12 days  
- **São Paulo** generated the highest number of orders  
- **Ajuricaba** and **Acucena** had most late deliveries  
- *"Security_and_services"* was the least-selling product category  

---

## 8. Limitations & Improvements
- Static Excel data model (not automated)  
- No DAX measures; logic based on Power Query and calculated columns  
- Could be enhanced using Power BI for improved visuals and scheduled refresh  

---

## 9. Conclusion
This project demonstrates how **Excel + Power Query** can replicate real-world business dashboards at low cost, delivering actionable business insights without advanced BI tools.
